# 红蓝对抗平台 — 测试计划

---

## 1. 引言

### 1.1 测试目标

本测试计划旨在验证红蓝对抗平台的功能完整性、性能可靠性和用户体验。通过系统化的测试，确保平台满足需求规格说明书中定义的所有功能性和非功能性需求。

### 1.2 测试范围

测试覆盖以下范围：
- 后端 REST API 接口（7 个端点）
- WebSocket 实时推送功能
- 红队攻击生成和变异进化功能
- 蓝队输入检测、工具审计和输出检测功能
- 目标智能体模拟和执行功能
- 评估报告生成功能
- 前端 UI 交互和可视化展示
- 数据库持久化和级联操作

### 1.3 测试环境

| 项目 | 配置 |
|------|------|
| 操作系统 | Windows 11 |
| Python | 3.10+ |
| 数据库 | SQLite 3.x |
| 浏览器 | Chrome 最新版 |
| Ollama 服务 | localhost:11434 |
| 红队模型 | dolphin-mistral:latest |
| 蓝队模型 | gemma2:2b |
| 目标模型 | qwen3:1.7b |

### 1.4 测试策略

采用分层测试策略：
- **单元测试**：针对各模块的核心函数进行独立测试
- **集成测试**：测试模块间接口调用和数据流转
- **端到端测试**：模拟用户完整操作流程
- **边界测试**：测试参数边界值和异常输入
