## 3. 许可信息

### 3.1 项目许可

本项目为软件项目实训课程作业，仅供学习交流使用。

### 3.2 第三方库许可

本项目使用的所有第三方库均为开源或免费使用，具体许可如下：

**MIT 许可证**：FastAPI、LangGraph、LangChain、SQLAlchemy、Pydantic、PyYAML、Vue、Vite、Pinia、Vue Router、Element Plus、Axios、Ollama

**BSD 许可证**：uvicorn、pandas、httpx、python-dotenv

**Apache 2.0 许可证**：TypeScript、ECharts、pyarrow、dolphin-mistral、qwen3

**Public Domain**：SQLite

**Gemma License**：gemma2

**商业 API**：DeepSeek API

### 3.3 使用限制

- 本项目仅供学习交流，不得用于商业用途
- 使用 DeepSeek API 需遵守 DeepSeek 服务条款
- 使用 Ollama 模型需遵守各模型的开源许可协议
- 平台生成的安全评估报告仅供内部参考，不构成正式的安全合规认证

## 6. 变更日志

### v1.0.0（2026-7）

**新增功能**：
- 任务管理：创建、启动、查询、详情、报告、审计事件
- 红队攻击：RedBench 数据集加载、LLM 攻击生成、5 种变异策略
- 蓝队防御：输入检测、工具审计、输出检测，双通道并发
- 目标模拟：金融智能体、客服智能体，沙箱执行
- 评估报告：6 项核心指标、RedBench 基准对比、AI 修复建议
- 实时可视化：WebSocket 推送、6 组件前端、断线重连
- 事件总线：双总线架构，21 种事件类型
- 数据库：5 张表，级联删除，自动创建
