## 5. 部署问题与解决

| 编号 | 问题描述 | 原因 | 解决方案 | 状态 |
|------|---------|------|---------|------|
| 1 | Ollama 模型拉取缓慢 | 网络带宽限制 | 使用国内镜像加速 | 已解决 |
| 2 | DeepSeek API 密钥未配置 | 未设置环境变量 | 配置 EXTERNAL_EVAL_API_KEY | 已解决 |
| 3 | 前端 WebSocket 连接失败 | 后端地址配置错误 | 修正前端 API 地址配置 | 已解决 |

## 6. 部署结论

### 6.1 总体评价

红蓝对抗平台已成功部署到目标环境，所有功能模块均通过验证测试。后端 7 个 REST API 端点和 1 个 WebSocket 端点全部正常工作，前端 6 个核心组件渲染正常，WebSocket 实时推送稳定。两种目标智能体类型（金融、客服）的完整对抗流程均验证通过。

### 6.2 部署状态

**部署成功**。

### 6.3 后续建议

1. 生产环境部署建议使用 Nginx 反向代理
2. 建议配置 Ollama 服务开机自启动
3. 建议定期备份数据库文件
4. 建议配置日志轮转，防止日志文件过大
